## 2. Arquitectura y Tecnologías
**Plataforma Móvil:** Android (Kotlin con Jetpack Compose)
**Entorno de Desarrollo:** Android Studio
**Hardware de Integración:**
1. Placa Arduino 
2. Módulo Bluetooth HC-05
3. Lector RFID MFRC522 y pantalla LCD 16x2

**Normas de Calidad Aplicadas:**

**ISO/IEC 25010:** Calidad del producto software (evaluación de adecuación funcional y usabilidad móvil).

**ISO/IEC 27001:** Lineamientos de seguridad en la transmisión de datos y control de accesos.

## 3. Guía de Instalación y Ejecución
1. Clonar o abrir el proyecto en **Android Studio**.
2. Conectar un dispositivo físico Android mediante USB con las opciones de **Depuración USB e Instalación vía USB** habilitadas en el modo desarrollador.
3. Compilar y ejecutar el paquete (`cl.inacap.atmiotapp`) directamente en el dispositivo móvil mediante el botón de ejecución (*Run*).
